# When the Output Looks Like Learning: Companion Site

This is the interactive companion website for the article **"When the Output Looks Like Learning: Tertiary Algorithmicity, Unproductive Success, and the Case for Pedagogical Friction in K–12 Schools"**.

Developed by **Micah Miner**, it serves as an educational tool for K–12 leaders and practitioners to analyze, diagnose, and redesign assignments to prevent AI cognitive bypass while fostering effortful schema construction.

## 🚀 Key Features

*   **Interactive Media Ecology Timeline**: Exploring Walter Ong's oral/literary stages leading up to *Tertiary Algorithmicity*.
*   **Unproductive Success Matrix**: Interactive 2x2 grid distinguishing productive failure from cognitive bypass.
*   **GPS vs. Map Canvas Simulation**: Real-time visual comparison of frictionless navigation vs. active search.
*   **C.O.R.E. & H.E.A.R.T. Frameworks**: Interactive lists of Micah Miner's ethical and emotional anchors for AI integration.
*   **Bypass Audit Diagnostic Tool**: A 5-step interactive quiz that calculates assignment bypass risk and provides custom recommendations.
*   **Targeted Printing**: Custom print styles that let users print specific frameworks, handouts, or audit scorecards directly.

## 🛠️ Tech Stack

*   **HTML5** (Semantic structure)
*   **Vanilla CSS3** (Responsive design, HSL color tokens, Glassmorphism, and Print stylesheets)
*   **JavaScript** (Interaction logic & canvas animations)

## 🌐 Deploying to GitHub Pages

To host this site live on GitHub Pages:
1. Push this repository to GitHub.
2. In your repository on GitHub, navigate to **Settings** -> **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Set the branch to `main` and directory to `/ (root)`.
5. Click **Save**. The site will be live at `https://<your-username>.github.io/<your-repo-name>/` in a few minutes!
