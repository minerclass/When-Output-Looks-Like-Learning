# When the Output Looks Like Learning

Static GitHub Pages companion site for Micah J. Miner's article, "When the Output Looks Like Learning," published in *i.e.: inquiry in education*, Volume 18, Issue 1, Article 4.

Source article: https://digitalcommons.nl.edu/ie/vol18/iss1/4/

## Purpose

This repository packages the digital companion as a lightweight static site. The companion helps readers explore the article's central concern: polished AI-generated schoolwork can satisfy familiar performance rubrics while bypassing the cognitive work those rubrics were meant to reveal.

The page is organized around:

- A classroom scenario involving an apparently proficient student essay
- Key terms such as tertiary algorithmicity, cognitive outsourcing, rhetorical saturation, and pedagogical friction
- A staged media-ecology frame extending Walter Ong's work
- The difference between visible performance and learning
- Design implications for educators and school leaders
